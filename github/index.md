# github — Workflows GitHub

Progressive disclosure: skills desta categoria (foco ID Consultoria).

- `codebase-inspection` — Inspecionar codebases com pygount (LOC, linguagens, proporções).
- `github-auth` — Setup de auth GitHub (tokens HTTPS, chaves SSH, login gh CLI).
- `github-code-review` — Revisar PRs: diffs, comentários inline via gh ou REST.
- `github-issue-to-pr` — Levar uma issue GitHub até um PR verificado com estado CI honesto.
- `github-issues` — Criar, triar, rotular, atribuir issues GitHub via gh ou REST.
- `github-pr-workflow` — Ciclo de vida de PR: branch, commit, open, CI, merge.
- `github-repo-management` — Clonar/criar/fork repos; gerenciar remotes e releases.
