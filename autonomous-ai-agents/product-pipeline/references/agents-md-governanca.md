# AGENTS.md na raiz do repositório do projeto

Governança de documentos. Sem isso, cada agente escolhe a própria hierarquia de verdade — e o
PRD perde para um comentário de reunião que ninguém sabe se foi decidido.

## O que registrar

**1. Hierarquia em caso de conflito** (padrão comprovado):

```
1. Decisão de reunião / transcrição
2. PRD
3. Documento de diretrizes
4. Demais documentos
```

Regra prática: decisão de reunião vence, e o PRD deve ser atualizado para refletir.

**2. Regra de sincronização com o Drive** — a subpasta "Produto" só é atualizada quando o
usuário sinalizar explicitamente que a sprint/quinzena terminou. Nunca automaticamente.

**3. Design system como referência visual de todos os documentos** — não só dos relatórios de
pesquisa. Quando o escopo ampliar, atualizar o AGENTS.md e a skill junto.

## Por que importa

O agente lê o repositório antes de agir. Se a hierarquia não estiver escrita, ele resolve
conflito por conta própria — e escolhe a versão que estiver mais à mão, não a que foi decidida.
