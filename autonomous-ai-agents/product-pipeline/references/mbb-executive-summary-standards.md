# MBB Executive Summary Standards

> Pesquisa sobre como McKinsey, BCG e Bain estruturam capas de relatório executivo.
> Fontes: deckary.com, poesius.com, slideworks.io

## Capa
- **Minimal**: título do engagement, cliente, data, logo. Nada mais.
- NADA de gradientes, glassmorphism, ícones grandes ou floreios.
- Cores: 2-3 da paleta da firma. A informação é o design.

## Executive Summary
- Framework **SCR** (Situation-Complication-Resolution)
- Resolução = **60-70%** do conteúdo
- **Bold-bullet**: negrito = claim, bullet = dado de suporte
- Ler só negritos = história completa
- 3-5 bullets, máx 300-500 palavras
- Zero "nós analisamos" — só findings

## Anti-padrões
- Gradientes decorativos → não renderizam em PDF
- Glassmorphism → quebra no Chromium print
- Citação sem dado → ocupa espaço sem comunicar
- Metadado na capa (consultoria, data, fase) → tira atenção
- "Sugerimos"/"acreditamos" → enfraquece

## Checklist
- [ ] SCR claro
- [ ] Negritos contam história sozinhos
- [ ] Zero floreios decorativos
- [ ] Dados suportam cada claim
- [ ] Silent read test OK
- [ ] page-break-after no header
- [ ] Sem labels nivel/status/projeto/data
- [ ] Seção "Sobre este Relatório" presente
