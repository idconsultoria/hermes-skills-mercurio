### Vetor (SVG) — reconstrução vetorial fiel ao manual

> Tipografia no SVG: `Clash Display 500` para wordmark + `Tomato Grotesk 400` para assinatura. Se a Tomato licenciada não estiver carregada, cai para Hanken Grotesk (proxy documentado no design system v5).

## Uso recomendado (manual)
- **Fundo claro** → use `positivo` (teal/charcoal)
- **Fundo escuro** → use `negativo`/`principal` (branco/mint)
- **Ícone/app/favicon** → use `simbolo`
- **Marca d'água / estamparia** → use `mono`
