# Caso ArtemisHub — 24/08/2026 (origem dos padrões em SKILL.md)

Diagnóstico e correções reais de uma sessão longa de dev numa app React(SPA)+FastAPI
(ArtemisHub). Cada bloco liga o sintoma observado à causa raiz e ao fix aplicado — o
SKILL.md generaliza; isto guarda o caso concreto e os endpoints/arquivos tocados.

## Contexto de stack
- Frontend React (Vite, framer-motion, react-router), backend FastAPI (`backend/main.py`),
  Postgres 17 no host. Middleware `enforce_api_key` protege TODOS os endpoints exceto
  `/api/health` e `/api/auth/login`.
- IA via proxy `/api/ia/chat` (usa credenciais da tabela `configuracoes.llm.*` —
  `llm.api_key`, `llm.base_url`, `llm.modelo`), com fallback de providers zen→go→zen-go.

## Diagnóstico 1 — "IA sempre mostra o mock SWOT genérico"
- Sintoma: "Analisar com IA" e "Consultor IA" sempre devolviam um mock genérico
  (SWOT/requirements estáticos) e o chat dava "Erro ao conectar com a Artemis".
- Investigação em 3 camadas:
  1. Config do banco: `llm.api_key = sk-fh4…GOcN` era o **valor mascarado** gravado
     (`v[:7]...v[-4:]`, 20 chars) — não chave real; `llm.base_url` estava com UM KEY
     (`sk-3Bd…`) no lugar da URL (alguém colou chave no campo de endpoint). Fix: corrigir
     no banco (banco ≠ `.env`; o app lê do banco para chat/análise, do `.env` para o crawl).
  2. Validar chave real contra o provedor: `curl -X POST <base>/chat/completions` — a 1ª
     chave deu `RegionError` (precisa opt-in China) e `CreditsError` (sem saldo); a chave
     nova deu `HTTP 200`. Ou seja: auth OK ≠ região/saldo OK.
  3. **Causa raiz final:** logs do backend mostravam `POST /api/ia/chat → 401` em massa.
     O frontend chamava com `fetch('/api/ia/chat', {headers:{'Content-Type':...}})` **sem
     `Authorization`** → middleware 401 → `analisarEdital` cai no `generateLocalAnalysis`
     (fallback local). Fix: adicionar `Authorization: Bearer ${getToken()}` (injectado de
     `@/lib/auth`) nas duas chamadas de `/api/ia/chat` em `src/lib/qwen.ts`.
- Lição-chave: **o fallback silencioso mascara o erro**; sempre olhar os logs do backend
  (401/500) antes de culpar chave/API.

## Diagnóstico 2 — "API 500: Internal Server Error" no Testar chamada real
- Endpoint `testar-llm` tem `@limiter.limit("10/hour")`. Após cliques repetidos, estourou
  o rate limit. O handler `_rate_limit_handler` fazia `raise HTTPException(429)` DENTRO de
  um exception handler → Starlette moderno converte em 500.
- Fix: retornar `JSONResponse(status_code=429, content={"detail": ...})` em vez de lançar.
  Contador em memória → `docker compose restart <backend>` zera.
- Detalhe: um endpoint com try/except amplo que retorna `{"ok":False,...}` NUNCA sobe 500
  por causa da chamada ao provider — 500 num endpoint de retry = outro bug (handler).

## Diagnóstico 3 — guard de config de IA
- `PUT /api/config/{chave}` aceitava lixo. Fix: validar `llm.base_url` começa com http/https
  e `llm.api_key` não tem `...` nem está fora do prefixo `sk-`. Isso evita recorrência
  (chave no campo de URL, máscara no campo de chave).

## Diagnóstico 4 — modal LGPD "pisca" entre viewport e container
- `<motion.div>` de `StepWrapper` com `initial={{ y: 12 }}` aplica `transform` no ancestral,
  criando **containing block**; o `position:fixed` do modal então ancorava no formulário e
  oscilava conforme o framer-motion re-aplicava transform (mouse disparava reflow).
- Fix: `createPortal(<ModalJSX/>, document.body)` em `react-dom` — aplicado em
  `LgpdConsent.tsx` e no atom `components/atoms/Modal.tsx`.

## Diagnóstico 5 — rodapé vira "tarja" sobre pill/conteúdo
- Preferência explícita do principal: **o único elemento fixo é a pill de navegação**;
  rodapé/créditos devem rolar com o conteúdo. Montar `<Footer/>` no `AppLayout`
  (`h-screen overflow-hidden`) criava faixa fixa.
- Fix: remover do AppLayout; montar `<Footer/>` no fim do conteúdo de CADA página rolável
  (11 páginas) e criar **token global** `.pb-pillnav { padding-bottom: 7rem }` no `index.css`
  para a pill não sobrepor o conteúdo (ex.: chat do edital). Ajuste em 1 lugar. Sem hardcode
  (`pb-28`) espalhado.

## Diagnóstico 6 — análise/chat vazam do edital anterior
- React Router reutiliza `EditalDetail` quando só o `:id` muda (sem remount) → `useState`
  (analise, messages, isFav) persistiam. Fix: `useEffect(..., [id])` com reset dos estados.

## Diagnóstico 7 — autofill CNPJ sem responsável/endereço
- API Minha Receita (`minhareceita.org/<cnpj>`) schema do QSA: `nome_socio`,
  `qualificacao_socio`, `cnpj_cpf_do_socio`, `nome_representante_legal`,
  `cpf_representante_legal` — NÃO `nome`/`cargo`. Mapper errado deixava campos vazios.
- Fix: mapear pelos campos reais; debounce 350ms para autofill ao completar 14 dígitos
  (CNPJ) / 8 dígitos (CEP, via ViaCEP `viacep.com.br/ws/<cep>/json`).

## Endpoints/arquivos tocados (referência de localização)
- `backend/main.py`: handler 429, guard `salvar_config`, credenciais `_llm_creds()`.
- `src/lib/qwen.ts`: header Bearer + prompt de preenchimento (resumo/tipo/contrapartida).
- `src/lib/cnpj.ts`, `src/lib/geo.ts`: mapper QSA + ViaCEP (autofill).
- `src/components/cadastro-empresa/steps/Etapa1Form.tsx`: autofill CEP/CNPJ.
- `src/components/cadastro-empresa/LgpdConsent.tsx`, `src/components/atoms/Modal.tsx`: portal.
- `src/App.tsx`, `src/index.css`, `src/components/layout/Footer.tsx`: rodapé rolável +
  token `.pb-pillnav`.
- `src/pages/*.tsx` (11): `<Footer/>` no fim do conteúdo rolável.
- `src/pages/EditalDetail.tsx`: reset por `[id]` + sumário/financials a partir da análise.
